PÁGINAS HTML ISOLADAS — PREVHELP

Abra qualquer arquivo .html com dois cliques. Cada página contém internamente seus estilos, scripts e imagens principais.

Arquivos:
- index.html — página inicial
- aposentadoria.html — página de aposentadoria
- redirect.html — atendimento padrão pelo WhatsApp
- redirect3.html — atendimento de aposentadoria pelo WhatsApp
- dash.html — painel administrativo
- politica-de-privacidade.html — política de privacidade
- termos-de-uso.html — termos de uso
- 404.html — página não encontrada

Observações:
- Formulários, métricas, painel e WhatsApp precisam de conexão com a internet.
- Os links entre as páginas funcionam quando todos os HTML permanecem na mesma pasta.
- Para publicar no Vercel, o projeto React original continua sendo a opção recomendada; este pacote serve como cópia independente das páginas.
